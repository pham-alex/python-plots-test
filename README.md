# Retail Sales Data Analysis

## Overview
This project explores a sample retail sales dataset generated using AI. I used Python, Pandas, and Matplotlib to organize the data, perform basic sales analysis, and create visualizations to identify patterns and trends in the dataset.

The goal of this project was to practice working with data and learn how to turn a dataset into meaningful visual insights.

## Technologies Used
- **Python** – Main programming language.
- **Pandas** – Used to organize, manipulate, and analyze the dataset.
- **Matplotlib** – Used to create charts and visualize the results.

## Dataset
The dataset was AI-generated for this project and contains 15 sample retail orders.

Each order includes information such as:
- Order ID
- Product name
- Product category
- Price
- Quantity sold
- Sales channel
- Payment method
- Promotion used
- Salesperson
- Customer rating

## Data Analysis & Visualizations

I performed several analyses to explore different aspects of the retail dataset:

1. **Total Sales by Product Category** – Compared total revenue across different product categories.
2. **Category vs. Payment Method** – Examined which payment methods were used across product categories.
3. **Category vs. Customer Rating** – Compared average customer ratings across product categories.
4. **Quantity vs. Promotion** – Analyzed the total quantity of products sold under each promotion.
5. **Salesperson vs. Total Sales** – Compared the total sales generated by each salesperson.
6. **Payment Method Distribution** – Used a pie chart to visualize the percentage of orders made with each payment method.
